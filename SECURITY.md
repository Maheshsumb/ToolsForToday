# Security Policy

ToolsForToday takes reports about security vulnerabilities seriously.

## Reporting a vulnerability

Please do not publish exploitable details, credentials, or private user data in a public issue or pull request.

If GitHub's **Report a vulnerability** option is available in the repository Security tab, use that private reporting channel. Its availability has not been verified by the maintainer in this review. If the private option is unavailable, email [maheshsumb.dev@gmail.com](mailto:maheshsumb.dev@gmail.com) with a concise description and safe reproduction steps. Do not include real credentials or personal data. The maintainer must confirm this mailbox is monitored for security reports before launch.

Please allow the maintainer reasonable time to investigate and coordinate a fix before public disclosure. Do not access, alter, or retain other people's data while investigating.

## Supported versions

The current production version is the only version considered for security updates. The project does not currently publish a formal release schedule.

## Security notes

Tool inputs and selected files are intended to be processed locally in the browser. Reports about unexpected uploads or analytics exposure should include the tool route and a synthetic reproduction, not real private content.
