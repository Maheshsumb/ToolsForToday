# Code of Conduct

This short Code of Conduct adapts the principles of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/); consult that linked document for the full template and attribution.

## Our standards

We aim to make participation welcoming and respectful to people with different backgrounds and levels of experience. Examples of helpful conduct include respectful disagreement, constructive feedback, acknowledging mistakes, and focusing on what is best for the community.

Unacceptable conduct includes harassment, insults, discriminatory or sexualized language, doxxing, and other unwelcome behavior in project spaces.

## Scope and enforcement

This code applies in project Issues, pull requests, discussions, and other project spaces. The project maintainer is responsible for reviewing reports and deciding on proportionate enforcement. No separate enforcement team is currently designated.

Report conduct concerns privately to the project maintainer at [maheshsumb.dev@gmail.com](mailto:maheshsumb.dev@gmail.com). Please do not post private or safety-sensitive details in a public issue. The maintainer should confirm this mailbox is monitored before public launch of this policy.

For the full terms, reporting guidance, enforcement process, and attribution, see the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
