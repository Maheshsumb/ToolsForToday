# Project plan

The launch scope is 12 free browser-based tools with no mandatory accounts, subscriptions, database, or paid APIs. Stages 01 and 02A establish the foundation and shared brand shell. Stage 02B builds the professional homepage and planned-tool catalogue. Stage 02C adds reusable tool-page UI; the catalogue entries remain coming soon and no tool engines are implemented.

1. Initial setup — completed: framework, static export, tokens, confirmation page, documentation, and validation.
2. Design system, homepage, and reusable tool-page UI — Stages 02A, 02B, and 02C completed; no tool engines included.
3. Five utility tools — exact tool scope to be agreed.
4. Three image tools — browser-side processing.
5. Four PDF tools — browser-side processing.
6. SEO and essential pages.
7. QA, accessibility, security and performance.
8. Cloudflare Pages deployment and custom domain — explicit deployment and DNS authorization required.
9. Post-launch analytics and monetization readiness — eventual advertising; no ad scripts now.

No work beyond the explicitly assigned stage is included; each future stage needs its own assigned scope.
